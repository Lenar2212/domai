# DomAI v77 — SPATIAL MODEL

## Добавлено
- пространственные узлы по этажам;
- вертикальные связи/колонны;
- горизонтальные балки;
- этажные плиты/диафрагмы;
- базовые опоры;
- связность между этажами;
- предварительное распределение нагрузок;
- коэффициенты использования элементов;
- карта критических элементов;
- TXT-отчёт;
- JSON-экспорт пространственной модели.

## Важно
v77 является концептуальной пространственной расчётной моделью и не является полноценным FEM/CAE-решателем. Здесь нет полноценной матрицы жёсткости, нормативного решателя перемещений, реальных конечных элементов, нелинейности, контакта грунта и полного набора нормативных проверок.

## Следующий этап
v78 — настоящий расчётный каркас FEM: степени свободы, узловая матрица жёсткости, сборка системы уравнений, граничные условия, решение перемещений и восстановление усилий в стержневых элементах. Его результаты также должны проходить инженерную верификацию.
