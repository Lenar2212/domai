# DomAI v79 — 3D FRAME FEM

Добавлен пространственный линейный frame FEM-каркас:
- 6 DOF на узел: UX, UY, UZ, RX, RY, RZ;
- 3D стержневой элемент;
- EA — осевая жёсткость;
- EIy/EIz — изгибная жёсткость;
- GJ — крутильная жёсткость;
- локальная система координат;
- преобразование локальной матрицы в глобальную;
- сборка глобальной матрицы;
- закрепление основания;
- решение перемещений;
- восстановление N, Vy, Vz, Mx, My, Mz;
- реакции;
- отчёт и JSON.

Ограничения:
Это прототип линейного пространственного frame FEM. Не реализованы оболочки/плиты, нелинейность, контакт грунта, второй порядок, устойчивость по нормативам, трещины железобетона, пластичность, сейсмика и полный нормативный набор сочетаний. Результаты требуют инженерной проверки и не являются автоматически сертифицированной рабочей документацией.

связать 3D FEM с реальными сечениями материалов DomAI v76, нагрузками v74/v75, комбинациями G/Q/S/W, автоматической проверкой U по элементам и 3D-картой деформированной формы.
