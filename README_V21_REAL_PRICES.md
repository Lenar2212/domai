# DomAI v21 — REAL PRICES

## Что добавлено
- Региональный расчёт цен.
- Публичные цены из реальных карточек товаров.
- Поставщик, регион, дата проверки и ссылка на источник у каждой позиции.
- Сравнение альтернатив.
- Расчёт регионального коэффициента.
- Отдельный API `/api/catalog/real`.
- Сохранён старый демонстрационный каталог v20.

## Важное ограничение
Это не live-интеграция с магазинами. Цены проверены по публичным страницам на 03.10.2026 и могут измениться. Региональный коэффициент — модель DomAI, а не тариф поставщика. Доставка, объём заказа, акции, наличие и условия оплаты не включены автоматически.

## Запуск
```bash
cd backend
python server.py
```
Затем открыть `frontend/index.html`.

DomAI остаётся концептуальным сервисом: расчёты не заменяют проектирование, инженерные изыскания, проверку нормативов, рабочую документацию и профессиональную экспертизу.
