# DomAI v50 — PROJECT FOR APPROVAL PREPARATION

Добавлен режим подготовки проекта после создания концепции дома.

Возможности:
- данные заказчика;
- адрес участка;
- кадастровый номер;
- регион/муниципалитет;
- площадь участка и дома;
- этажность и назначение;
- описание проекта;
- чек-лист подготовки;
- оценка заполненности чек-листа;
- сохранение проекта;
- экспорт структурированного JSON;
- печатный предпросмотр, который можно сохранить в PDF через браузер;
- перенос визуальных параметров из предыдущих версий DomAI.

ВАЖНО:
DomAI формирует предварительный/концептуальный пакет для подготовки и обсуждения. Наличие этого пакета не означает, что он соответствует всем требованиям конкретного органа согласования или автоматически будет принят. Перед официальной подачей необходимо проверить актуальные требования по конкретному участку и, если требуется, привлечь профильного специалиста.
