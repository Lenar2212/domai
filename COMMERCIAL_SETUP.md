# DomAI v53 — коммерческий запуск

Добавлено: тарифы, аккаунт-прототип, проекты, коммерческое предложение и Render-конфигурация.

Важно: аккаунт и проекты в этой версии демонстрационные и хранятся в браузере. Перед реальным запуском нужны серверная авторизация, PostgreSQL, безопасные сессии, webhook оплаты и выдача платных функций после подтверждения платежа. Платёжные ключи нельзя помещать во frontend.

Render: подключить GitHub → New → Web Service → Python. Build: `pip install -r requirements.txt`; Start: `python backend/server.py`. Render выдаёт публичный адрес и поддерживает собственный домен.
