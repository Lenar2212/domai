# DomAI v82 — UNIFIED BIM/FEM

Объединены:
- геометрия помещений v81;
- этажи и площади;
- расчётные нагрузки G/Q/S/W;
- автоматическая расчётная сетка;
- балки;
- колонны;
- плиты как нагрузочные области;
- опоры;
- материал и сечение;
- предварительные U-N/U-M/U-def;
- критические элементы;
- единый инженерный JSON/TXT отчёт.

Ограничения:
Это интеграционный инженерный прототип. Плиты не являются полноценными shell FE, стены и фундамент не являются полноценными объёмными/контактными FE, нормативные сочетания требуют региональной настройки, а автоматическое распознавание несущей схемы является эвристическим. Результат не является автоматически сертифицированным расчётом или рабочей документацией.
