# DomAI v107 — COMMERCIAL LAUNCH

Цель v107 — превратить DomAI в запускаемый коммерческий веб-сервис.

## Что уже есть
- регистрация и вход;
- личный кабинет;
- проекты в SQLite;
- тарифы Free / Дом / PRO / Профи;
- создание заказа;
- подготовка YooKassa redirect + webhook;
- история заказов;
- платная выдача последнего проекта;
- панель владельца при `is_admin=1`;
- инженерные модули v100–v106;
- предварительные PDF/HTML-пакеты.

## Как запустить локально

```bash
./start_local.sh
```

Открыть `http://localhost:8000`.

## Как запустить в интернете

Рекомендуемый путь — Render или другой Python hosting.

Переменные:
- `PORT`
- `DATABASE_URL` (для production рекомендуется PostgreSQL после полной миграции схемы)
- `YOOKASSA_SHOP_ID`
- `YOOKASSA_SECRET_KEY`
- `DOMAI_ADMIN_BOOTSTRAP_KEY`

Для первого владельца:
1. зарегистрировать аккаунт;
2. выполнить bootstrap администратора с секретным ключом;
3. проверить `/api/me` и панель владельца.

## Важный production checklist

Перед реальными продажами необходимо:
- проверить webhook YooKassa по подписи/подлинности и идемпотентность;
- завершить PostgreSQL-миграцию и резервное копирование;
- включить rate limiting;
- добавить CSRF-защиту для cookie-сессий, если схема авторизации будет изменена;
- настроить домен и HTTPS;
- опубликовать пользовательское соглашение, политику ПД и условия возврата;
- проверить налоговый/кассовый режим продавца;
- юридически проверить модель продажи инженерных результатов.
