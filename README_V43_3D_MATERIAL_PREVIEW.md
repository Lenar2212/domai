# DomAI v43 — 3D MATERIAL PREVIEW

Добавлена связь каталога v42 с 3D-сценой.

При наличии объектов с семантическими типами 3D-рендерер может визуально менять:
- фасад;
- крышу;
- окна;
- двери;
- ворота;
- забор;
- газон;
- деревья.

Состояние материалов берётся из localStorage:
- `domai_v41_style`
- `domai_v42_materials`

Также добавлено сохранение визуального состояния `domai_v43_visual_state`.

Важно:
это визуальный предварительный просмотр. Образцы цветов/материалов не являются точными текстурами или спецификацией производителя.
