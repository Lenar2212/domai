# DomAI v77 — STRUCTURAL GRID

Добавлена автоматическая концептуальная структурная сетка на основе текущей геометрии помещений.

## Состав
- оси X/Y;
- кандидаты несущих стен по границам помещений;
- узлы колонн на пересечениях сетки;
- балки по структурным линиям;
- плиты по контурам этажей;
- фундаментные ленты по контурам;
- сводка количества элементов;
- TXT-отчёт;
- JSON-экспорт структурной модели.

## Ограничение
Алгоритм определяет кандидаты структурных элементов эвристически. Он не доказывает, что конкретная стена является несущей, а конкретная колонна или балка допустима по прочности. Для рабочего проекта нужны реальные схемы опирания, сечения, материалы, нагрузки, узлы, геология и проверка квалифицированным специалистом.
