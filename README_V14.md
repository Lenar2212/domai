# DomAI v14 — 3D Constructor

Добавлен браузерный интерактивный 3D-слой на Three.js:
- OrbitControls: вращение/панорамирование/масштаб;
- участок и ограждение;
- дом с 1–3 этажами;
- окна;
- крыша;
- гараж, баня, сад и дорожки;
- вид сверху;
- автоматическое обновление 3D при изменении участка.

Запуск:
1. `cd backend && python server.py`
2. открыть `frontend/index.html`.
3. Для 3D нужен доступ браузера к CDN Three.js.

Это визуальный конструктор, не BIM, не рабочая проектная документация и не строительная экспертиза.
