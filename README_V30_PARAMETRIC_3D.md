# DomAI v30 — PARAMETRIC 3D

v30 развивает v29 в сторону параметрического 3D-редактора.

## Добавлено
- перетаскивание комнат мышью по X/Z;
- привязка к настраиваемой сетке;
- численное редактирование X/Z/ширины/глубины;
- автоматическое ограничение элементов границами дома;
- перетаскивание дверей и окон;
- центрирование выбранного элемента;
- событие синхронизации данных с 2D-планом;
- сохранение проекта через существующий API и JSON fallback.

## Важно
Это концептуальный редактор. Автоматическое изменение несущих конструкций, расчёт нагрузок, инженерных сетей, геологии, BIM-топологии и рабочей документации не реализованы и не должны подразумеваться пользователем.

Перед строительством результаты необходимо проверять у профильных специалистов и по применимым требованиям.
