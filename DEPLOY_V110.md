# DomAI v110 — запуск

1. Загрузить проект на Render.
2. Заполнить secrets:
   - YOOKASSA_SHOP_ID
   - YOOKASSA_SECRET_KEY
   - DOMAI_ADMIN_BOOTSTRAP_KEY
   - DOMAI_SELLER_NAME
   - DOMAI_SELLER_INN
   - DOMAI_SELLER_STATUS
   - DOMAI_SELLER_EMAIL
   - DOMAI_SELLER_ADDRESS
3. Открыть `/api/launch-gates`. Все ключевые проверки должны быть true, особенно `ready_for_paid_sales`.
4. Открыть юридические страницы. В них должны отображаться заполненные реквизиты вместо [ФИО]/[ИНН].
5. Создать тестовый аккаунт и проверить бесплатный тариф.
6. В тестовом режиме YooKassa проверить создание платежа и webhook.
7. Только после проверки включать реальные продажи.

Важно: сервис не выдаёт автоматически сертифицированную или утверждённую проектную документацию. Инженерные расчёты — предварительные.
