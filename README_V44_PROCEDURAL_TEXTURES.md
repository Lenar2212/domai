# DomAI v44 — PROCEDURAL TEXTURES

Добавлены процедурные текстуры, генерируемые непосредственно в браузере:
- фасад: штукатурка, кирпич, дерево, камень, сайдинг;
- крыша: металл, черепица, мягкая кровля, дерево;
- забор: профнастил, дерево, штакетник, сетка.

Текстуры создаются Canvas API и могут передаваться 3D-рендереру через:
- `domai44CanvasTexture(kind)`
- `domai44SetTexture(object, texture)`

Выбранный набор сохраняется в `domai_v44_textures`.

Это визуальные процедурные образцы, а не фотографии или точные текстуры производителя.
