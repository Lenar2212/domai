# DomAI v83 — UNIFIED STRUCTURAL SOLVER

v83 добавляет единый расчётный цикл:
- четыре сочетания G/Q/S/W;
- сборка глобальной матрицы жёсткости для стержневой модели;
- передача распределённых нагрузок в узловые эквиваленты;
- решение перемещений;
- восстановление продольных усилий N;
- выбор наиболее неблагоприятного сочетания для элемента;
- U по напряжению относительно выбранного материала;
- максимальные перемещения;
- критические элементы;
- единый отчёт/JSON.

Ограничения:
- линейный стержневой solver;
- плиты/стены/фундамент пока не являются полноценными shell/solid/contact конечными элементами;
- отсутствуют нелинейность и полноценный второй порядок;
- нормативные сочетания и проверки должны быть верифицированы для конкретных норм и региона;
- результат не является автоматически сертифицированным расчётом или рабочей документацией.

Следующий этап v84:
полноценные изгибные 3D frame элементы с 6 DOF, N/Q/M, а также автоматическая передача нагрузок от плит и стен на узлы/стержни с проверкой равновесия.
