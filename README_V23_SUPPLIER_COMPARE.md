# DomAI v23 — SUPPLIER COMPARE

Добавлено:
- каталог поставщиков;
- несколько предложений на один материал;
- сравнение цены по поставщикам;
- расчёт суммы по количеству из проекта;
- ссылка на источник каждого предложения;
- поле наличия `проверить`;
- API `/api/suppliers` и `/api/market/compare`.

### Почему наличие отмечено «проверить»
DomAI не выдаёт статическое значение за live-остаток. Для настоящего коммерческого режима нужны официальный API, партнёрский feed или разрешённый механизм импорта данных конкретного поставщика.

### Важно
Цены других поставщиков в демонстрационном сравнении обозначены как ориентиры/аналоги и не должны считаться подтверждёнными офертами. Перед покупкой пользователь должен перейти к источнику и проверить актуальные цену, товар, наличие и доставку.
