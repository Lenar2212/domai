# DomAI v34 — AI PLANNER

## Возможности
- генерация концептуальной планировки по числу спален и санузлов;
- кухня-гостиная;
- гардеробные;
- котельная;
- кабинет;
- постирочная;
- несколько этажей;
- учёт заданной общей площади;
- обработка свободного текстового пожелания;
- автоматическая расстановка помещений по этажам;
- концептуальные двери и окна;
- оптимизация площадей;
- синхронизационные события для 2D/3D;
- сохранение через API или JSON.

Планировщик детерминированный и работает без внешнего API/LLM.

## Важно
Результат является предварительной концепцией. Алгоритм не выполняет архитектурные, конструктивные, инженерные, пожарные, санитарные или иные обязательные расчёты и не создаёт рабочую проектную документацию.
