# DomAI v80 — ENGINEERING FEM

Добавлена инженерная связка:
- G — постоянная нагрузка;
- Q — полезная;
- S — снег;
- W — ветер;
- предварительные ULS/SLS-сочетания;
- передача результатов 3D frame FEM;
- автоматические U-N, U-M, U-V и U-def;
- итоговый коэффициент U;
- статусы OK / ТРЕБУЕТ ПРОВЕРКИ / НЕ ПРОХОДИТ;
- список критических элементов;
- условная карта деформированной схемы;
- TXT и JSON отчёты.

ВАЖНО:
Сочетания и проверки являются инженерным прототипом. Для рабочего расчёта необходимо привязать нагрузки к региональным нормативным значениям, фактическим сечениям, материалам, граничным условиям, расчётным ситуациям и нормативным коэффициентам. ПО не выдаёт автоматически сертификат, экспертное заключение или юридически действующую рабочую документацию.
