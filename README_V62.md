# DomAI v62 — 3D EDITOR

Added a dedicated Three.js 3D editor:
- select rooms directly in the 3D scene;
- edit X/Y position;
- edit width/depth;
- edit wall height;
- edit conceptual wall thickness;
- rebuild the room geometry;
- sync changes back to the v60 2D state;
- save the resulting conceptual layout.

This is a visualization/concept tool and not structural BIM or working project documentation.
