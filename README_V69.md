# DomAI v69 — ENGINEERING ENGINE

## Что добавлено
- единая расчётная модель объекта;
- исходные данные здания и основания;
- нагрузки G/Q/S/W;
- расчётная комбинация нагрузок;
- предварительная проверка среднего давления на грунт;
- контроль геометрических и входных условий;
- нормативно-ориентированный workflow документации;
- комплектование ПЗ/ПЗУ/АР/КР/ИОС/РР/СО;
- статусы: концепция → расчёт → подготовка РД → проверено ответственным специалистом;
- текстовый инженерный отчёт.

## Нормативная база оформления
Структура рабочего процесса ориентирована на ГОСТ Р 21.101-2026, действующий с 01.04.2026.

## Критическое ограничение
DomAI не объявляет автоматически расчёт сертифицированным и не присваивает документам юридическую силу. Сертификация, экспертиза, подписание и выпуск рабочей документации выполняются уполномоченными специалистами/организациями в предусмотренном порядке.

Для реального инженерного расчёта следующими этапами должны стать: инженерно-геологические данные, расчётные схемы МКЭ/проверочные модели, детальные проверки железобетона/металла/дерева/кладки, устойчивость, прогибы, трещиностойкость, фундаменты и осадки, узлы и спецификации.
