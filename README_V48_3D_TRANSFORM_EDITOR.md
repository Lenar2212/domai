# DomAI v48 — 3D TRANSFORM EDITOR

Добавлена панель трансформации выбранного 3D-объекта.

Параметры:
- X, Y, Z;
- ширина;
- высота;
- глубина;
- поворот вокруг Y;
- применение в реальном времени;
- чтение текущих параметров;
- сброс;
- сохранение последней трансформации в localStorage.

Работает совместно с выбором объекта из DomAI v47.

Важно: размеры и геометрия являются концептуальными визуальными параметрами. Это не рабочая строительная документация.
