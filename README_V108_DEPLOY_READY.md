# DomAI v108 — DEPLOY READY

Коммерческая ветка DomAI, подготовленная для публикации в интернете.

## Вход клиента

Главная страница → регистрация → личный кабинет → создание проекта → инженерные модули → тариф → заказ → оплата → выдача предварительного результата.

## Владелец

`DOMAI_ADMIN_BOOTSTRAP_KEY` позволяет назначить зарегистрированный email администратором. После этого доступны `/api/admin/stats`, `/api/admin/orders` и админский интерфейс, если он включён фронтендом.

## Production

Render blueprint находится в `render.yaml`; Dockerfile добавлен как альтернативный способ развёртывания.
