# DomAI v77 — ELEMENT CHECKS

Результаты Load Path v74 передаются в предварительные проверки отдельных конструкций.

## Проверяются
- балки: условная прочность + прогиб;
- плиты: условная прочность + прогиб;
- колонны: условная осевая несущая способность;
- несущие стены: условная вертикальная несущая способность;
- фундаментные участки: условная несущая способность + давление на грунт;
- единый коэффициент использования U;
- OK / ТРЕБУЕТ ПРОВЕРКИ / НЕ ПРОХОДИТ;
- TXT-отчёт;
- JSON-экспорт.

## Важно
Формулы v75 являются упрощёнными предварительными индикаторами. Это не полноценный нормативный расчёт конструкций и не сертификат. Для рабочего проекта нужны нормативные сочетания, реальные материалы и сечения, расчёт устойчивости, трещиностойкости, продавливания, анкеровки, узлов, основания и другие проверки с последующей проверкой квалифицированным специалистом.

## Следующий этап
v76 — расширенный нормативный расчётный движок: материалы, сочетания нагрузок, расчётные сопротивления, изгиб/срез/сжатие/устойчивость/прогиб, фундамент по слоям и сводный паспорт расчёта.
