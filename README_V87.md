# DomAI v87 — BIM → UNIFIED FEM MESH

v87 связывает геометрию BIM с расчётной сеткой:
- помещения становятся shell-областями;
- этажи задают пространственное положение;
- балки/колонны становятся frame-линиями;
- ближайшие узлы автоматически объединяются по геометрическому допуску;
- выделяются общие shell/frame узлы;
- определяются опорные узлы;
- нагрузки группируются по этажам;
- формируется единая mesh-структура и JSON.

Ограничения:
- shell FEM всё ещё упрощённая;
- не реализованы полноценные узловые связи, MPC/constraint equations и
  сопряжение оболочка-стержень с передачей всех 6 DOF;
- нет нормативной проверки армирования, устойчивости, трещин, продавливания,
  нелинейности и геотехнической модели.

Следующий v88:
реально собрать эту BIM-сетку в одну глобальную K/F/U модель, выполнить
совместимость shell↔frame по 6 DOF, распределить нагрузки по этажам и получить
N/Q/M + shell усилия/напряжения в едином результате.
