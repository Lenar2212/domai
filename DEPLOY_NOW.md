# DomAI v108 — запуск в интернете

## Вариант 1: Render

1. Создайте аккаунт на Render.
2. Создайте новый Web Service из Git-репозитория, куда загружен этот проект.
3. Render увидит `render.yaml`; либо укажите:
   - Build: `pip install -r requirements.txt`
   - Start: `python backend/server.py`
4. После первого запуска откройте адрес вида `https://domai-business-....onrender.com`.
5. Проверьте `https://ВАШ-АДРЕС/api/health` — должен вернуться JSON с `ok: true`.
6. Зарегистрируйте обычный пользовательский аккаунт.
7. Для назначения администратора выполните POST `/api/admin/bootstrap` с JSON:
   `{ "key": "ваш DOMAI_ADMIN_BOOTSTRAP_KEY", "email": "ваш-email" }`
8. В настройках Render задайте `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY` после подключения магазина YooKassa.

## Домен

В Render откройте Settings → Custom Domains и добавьте свой домен. После настройки DNS Render выдаст HTTPS-сертификат.

## Важно о базе

v108 использует SQLite в каталоге `DOMAI_DATA_DIR`. Для Render blueprint подключён постоянный диск `/var/data`. `DATABASE_URL` оставлен для дальнейшей миграции на PostgreSQL, но текущая версия не переключает всю схему на PostgreSQL автоматически.

## Перед реальными продажами

- проверить webhook YooKassa и идемпотентность;
- проверить чеки/кассовый режим и налогообложение;
- добавить пользовательское соглашение, политику обработки ПД и условия возврата;
- провести тестовый платёж;
- сделать резервное копирование базы;
- проверить юридическую модель продажи инженерных материалов.

Инженерные результаты DomAI в этой версии — предварительные/концептуальные материалы, не рабочая и не сертифицированная проектная документация.
