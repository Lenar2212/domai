# DomAI v55 — реальная оплата через ЮKassa

В коде добавлена серверная интеграция с API ЮKassa и webhook.

ЮKassa создаёт платеж на сервере и возвращает `confirmation_url`, куда перенаправляется клиент. Статус оплаты подтверждается webhook-событием `payment.succeeded`.

Переменные окружения:
- `YOOKASSA_SHOP_ID`
- `YOOKASSA_SECRET_KEY`

Их нельзя помещать в frontend, GitHub или ZIP.

Webhook:
`POST https://ВАШ-ДОМЕН/api/payment/yookassa-webhook`

Для ЮKassa в личном кабинете укажите HTTPS URL webhook и включите событие `payment.succeeded`.

После получения webhook DomAI переводит заказ в `paid`.

## Перед боевым запуском
- получить магазин ЮKassa и выполнить требования провайдера;
- настроить чеки/фискализацию в соответствии с применимыми требованиями;
- использовать PostgreSQL вместо SQLite для production;
- добавить проверку актуального статуса платежа через API перед выдачей платных функций;
- добавить идемпотентность обработки webhook;
- настроить резервное копирование и журналирование.
