# DomAI v15 AI Planner

Главная функция версии — генерация эскиза участка по обычному русскому описанию.

Пример:
«Участок 20×30 м. Дом 150 м², 2 этажа, 3 спальни, гараж на 2 машины, баня, терраса, сад и мангал».

Система создаёт:
- участок;
- дом;
- помещения;
- дополнительные объекты;
- 2D-представление;
- 3D-представление.

Ограничение: автоматический результат является предварительным эскизом и не является рабочей проектной документацией.
