# DomAI v45 — 3D MATERIAL EDITOR

Редактор визуального оформления концептуальной 3D-сцены.

Функции:
- фасад: штукатурка / кирпич / дерево / камень / сайдинг;
- крыша: металл / черепица / мягкая кровля / дерево;
- забор: профнастил / дерево / штакетник / сетка;
- применение процедурной текстуры к 3D-мешам по семантическому типу;
- сохранение оформления в localStorage;
- случайный комплект;
- режим сравнения «до / после»;
- резервное сохранение состояния.

Важно: визуальные материалы являются концептуальной демонстрацией. Это не рабочий строительный проект, не спецификация производителя и не основание для строительства.
