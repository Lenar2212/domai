# DomAI v41 — APPEARANCE EDITOR

Добавлен конструктор внешнего вида.

Настраиваются:
- цвет фасада;
- цвет крыши;
- цвет окон;
- цвет дверей;
- цвет ворот;
- цвет забора;
- цвет газона;
- цвет деревьев;
- стиль забора: сплошной, штакетник, деревянный, сетка.

Есть:
- применение стиля;
- случайный вариант;
- сброс;
- сохранение в localStorage;
- событие `domai41style` для подключения к 3D-рендереру.

Версия подготовлена как слой визуальных настроек, который можно подключать к 3D-сцене v36/v37/v40 без изменения модели проекта.

Важно: цвета и материалы являются визуальной концепцией и не являются спецификацией реальных материалов или гарантией их характеристик.
