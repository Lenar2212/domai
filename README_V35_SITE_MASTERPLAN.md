# DomAI v35 — SITE MASTERPLAN

## Добавлено
- генерация концептуального генерального плана;
- участок с настраиваемыми размерами;
- дом;
- гараж на 1/2 автомобиля;
- парковка;
- баня;
- терраса;
- сад;
- мангальная зона;
- дорожки;
- проверка выхода объектов за границы;
- проверка простых пересечений объектов;
- оптимизация размещения;
- 2D визуализация генплана;
- сохранение через API или JSON.

## Ограничения
Положение объектов является концептуальным. Алгоритм не проверяет автоматически все градостроительные ограничения, охранные зоны, инсоляцию, пожарные разрывы, сети, рельеф, геологию, красные линии, сервитуты и местные требования. Перед строительством генплан должен быть проверен специалистами и по применимым нормам.
