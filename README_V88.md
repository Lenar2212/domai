# DomAI v88 — GLOBAL BIM FEM

v88 собирает BIM-сетку в единую численную модель:
- Frame + Shell;
- общие 6 DOF на узел;
- глобальная матрица K;
- глобальный вектор F;
- решение U;
- нагрузки по этажам;
- контактные вертикальные пружины;
- реакции;
- контроль равновесия;
- Frame: N/Vy/Vz/Mx/My/Mz;
- Shell: давление и перемещения;
- несколько сочетаний G/Q/S/W;
- выбор наиболее неблагоприятного результата;
- TXT/JSON.

Ограничения:
shell-формулировка пока упрощённая; нет полноценного verified shell FEM,
MPC/constraint equations, реального сопряжения 6 DOF shell-frame,
нелинейного soil contact, армирования, устойчивости, трещин, продавливания,
второго порядка и полного нормативного движка.

Результат не является автоматически сертифицированным расчётом или рабочей документацией.

Следующий v89:
нормализовать единицы, реализовать корректные shell DOF/локальные матрицы,
MPC/compatibility shell-frame, реальные распределённые нагрузки по площади,
и независимые benchmark-тесты против эталонных аналитических решений.
