# DomAI v18 — Wall Editor

Добавлено:
- выбор комнаты;
- выбор правой или нижней стены;
- изменение стены на заданное количество метров;
- автоматический пересчёт площади;
- сдвиг соседних помещений;
- нормализация планировки;
- контроль суммарной площади этажа;
- обновление 2D и 3D.

Ограничение: геометрический алгоритм демонстрационный. Он не заменяет архитектурный/конструкторский расчёт.
