# DomAI v15 — AI-проектировщик

Пользователь пишет пожелания обычным языком. Встроенный локальный парсер:
- определяет размеры участка;
- определяет площадь и этажность дома;
- распознаёт спальни, гараж, баню, террасу, сад, мангал;
- формирует предварительный список помещений;
- автоматически размещает объекты;
- передаёт результат в 2D/3D.

Для production вместо локального парсера можно подключить LLM, но её результат должен проходить структурную валидацию и compliance-проверки.
