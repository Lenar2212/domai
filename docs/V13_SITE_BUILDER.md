# DomAI v13 — Site Builder

Добавлено:
- 2D-конструктор участка;
- изменение размеров участка;
- дом, гараж, баня, сад, дорожки;
- перетаскивание объектов;
- обнаружение выхода за границы;
- обнаружение пересечений;
- предварительная проверка расположения дома;
- демонстрационный 3D-вид;
- сохранение проекта в аккаунт.

Ограничение: геометрическая проверка не является кадастровой, градостроительной или строительной экспертизой.
