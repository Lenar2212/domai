# DomAI v20 — Material Catalog

Добавлено:
- JSON-каталог материалов;
- категории;
- единицы измерения;
- демонстрационные цены;
- поставщик/источник;
- альтернативные материалы;
- подбор материалов под дом;
- сравнение вариантов;
- расчёт потенциальной экономии.

Для production каталог должен получать данные из проверенных прайсов/API поставщиков с датой обновления и регионом цены.
