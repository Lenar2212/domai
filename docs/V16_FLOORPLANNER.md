# DomAI v16 — AI Floor Planner

Добавлено:
- автоматическое распределение помещений по этажам;
- до 3 этажей;
- лестничный узел на верхних этажах;
- автоматические концептуальные двери;
- автоматические концептуальные окна;
- интерактивное переключение этажей;
- визуальный 2D-план этажей;
- передача той же структуры в дальнейший 3D-слой.

Ограничение: планировка концептуальная. Перед строительством необходима профессиональная архитектурная/конструкторская разработка и проверка исходных данных.
