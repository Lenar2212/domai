# DomAI v12 Commercial

Компоненты:
- frontend: браузерный интерфейс;
- backend/server.py: API;
- SQLite: пользователи, сессии, проекты, аудит;
- compliance.py: автоматическая проверка рисков;
- estimate(): предварительная оценка;
- plan(): автоматический эскиз помещений.

## Запуск
1. `cd backend`
2. `python server.py`
3. Открыть `frontend/index.html`.

Для публичного запуска нужны HTTPS, нормальная серверная аутентификация, rate limiting, резервное копирование, секреты в окружении, миграции БД, CSRF/CORS-настройки и профессиональный аудит безопасности.
