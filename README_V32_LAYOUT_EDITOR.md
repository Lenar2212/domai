# DomAI v32 — LAYOUT EDITOR

## Добавлено
- создание и удаление помещений;
- изменение ширины, глубины, X/Z;
- автоматический пересчёт площади каждого помещения и общей площади;
- концептуальное создание внутренних перегородок;
- разделение выбранной комнаты на две;
- концептуальная автоматическая расстановка дверей;
- концептуальная автоматическая расстановка окон;
- единое состояние помещений/проёмов для 3D;
- сохранение через существующий API или JSON fallback.

## Важно
Редактор предназначен для предварительной визуализации и планировочных сценариев. Он не выполняет расчёт несущих конструкций, пожарных расстояний, инженерных систем, теплотехники, геологии или других обязательных проектных расчётов. Результат не является рабочей проектной документацией.
