# DomAI v52 — DIMENSIONED DRAWINGS

Добавлен предварительный чертёжный слой:
- габаритные размеры здания;
- внутренние размеры;
- оси;
- условные окна и двери;
- площади помещений;
- площадь пятна застройки;
- периметр;
- толщина стены;
- высота этажа;
- печатный лист и сохранение в PDF через браузер.

Все геометрические данные в этой версии являются концептуальными. Листы не являются рабочей архитектурной/конструктивной документацией и должны проверяться специалистом перед официальным использованием.
