# DomAI v56 — кабинет и админ-панель

## Что добавлено
- `/api/me` — аккаунт и текущий тариф;
- `/api/orders` — история заказов;
- entitlement — право на тариф после успешной оплаты;
- `/api/admin/stats` — пользователи, проекты, заказы, оплаченные заказы, выручка;
- `/api/admin/orders` — список последних заказов;
- `/api/admin/bootstrap` — одноразовое назначение администратора по секрету.

## Первый администратор
После создания обычного аккаунта задайте на сервере:
`DOMAI_ADMIN_BOOTSTRAP_KEY=<длинный секрет>`

Затем POST на:
`/api/admin/bootstrap`
с JSON:
`{"email":"ваш@email","key":"секрет"}`

После назначения администратора секрет можно удалить из настроек сервера.

## Важно для production
SQLite подходит для прототипа/одного экземпляра. Для серьёзного коммерческого запуска следует перейти на PostgreSQL, добавить безопасное хеширование паролей (Argon2/bcrypt), rate limiting, резервные копии и полноценную обработку webhook с идемпотентностью.
