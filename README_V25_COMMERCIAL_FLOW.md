# DomAI v25 — COMMERCIAL FLOW

## Сценарий
1. Пользователь формирует проект.
2. Указывает участок и параметры дома.
3. DomAI сохраняет проект.
4. Формируется концептуальный отчёт.
5. Материалы и поставщики остаются доступны из v23/v24.
6. Пользователь может отправить заявку.
7. Заявка сохраняется в SQLite.

## Экспорт
В прототипе отчёт экспортируется в JSON. Это сделано намеренно: для настоящего PDF нужны типографика, шаблон, реквизиты и юридические тексты.

## Правовая граница
DomAI не должен выдавать концептуальный результат за рабочую проектную документацию, строительную смету или инженерные изыскания. Перед коммерческим запуском необходимо отдельно настроить оферту, политику персональных данных, согласия, обработку заявок и порядок привлечения квалифицированных проектировщиков.
