# DomAI v18 Wall Editor

Версия добавляет редактирование стен и базовую параметрическую реакцию соседних комнат.

Сценарий:
1. AI создаёт план.
2. Пользователь выбирает комнату.
3. Меняет стену на +/− метры.
4. Площадь комнаты пересчитывается.
5. Соседние помещения сдвигаются.
6. 2D и 3D обновляются.
