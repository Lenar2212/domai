# DomAI v104 — ENGINEERING NETWORKS 2D + 3D

## Что добавлено
- Визуализация инженерных сетей v102/v103 одновременно на 2D-плане и в 3D.
- Электрика, газ, водоснабжение, канализация, отопление.
- Фильтрация по системе и этажу.
- Высота прокладки и этаж учитываются при построении 3D.
- Внешние участки инженерных сетей отображаются в общей координатной схеме.
- Экспорт JSON и текстовый отчёт.

## Ограничения
Модель является концептуальной. Автоматическая трассировка не заменяет рабочее проектирование, расчёт сечений кабелей, защит, токов КЗ, диаметров и расходов, гидравлический расчёт, расчёт уклонов канализации, газоснабжение, вентиляцию, пожарные требования и проверку квалифицированным проектировщиком.

3D-визуализация предназначена для пространственной координации и предварительного планирования, а не для выдачи сертифицированной рабочей документации.
