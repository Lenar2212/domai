# DomAI v77 — GEOMETRY STRUCTURAL

## Добавлено
- извлечение помещений из текущей 2D-модели DomAI;
- определение площадей этажей;
- определение габаритов этажей;
- определение этажности по полю floor/level;
- оценка пролётов по фактическим размерам помещений;
- эвристическое определение количества несущих линий;
- автоматическое накопление вертикальных реакций сверху вниз;
- связка геометрия → перекрытие → опоры → фундамент → грунт;
- таблица реакций по этажам;
- предупреждения по крупным пролётам и неполной модели;
- TXT-отчёт;
- JSON-экспорт структурной модели.

## Ограничения
Это предварительная инженерная модель. Эвристическое определение несущих линий не заменяет проектирование несущей системы. Для рабочего расчёта нужны реальные опоры, пролёты, материалы, сечения, узлы, сочетания нагрузок, геология, расчёт основания и профессиональная проверка.
