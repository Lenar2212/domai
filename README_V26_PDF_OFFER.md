# DomAI v26 — PDF COMMERCIAL OFFER

Добавлено:
- генерация коммерческого PDF;
- титульная страница;
- исходные данные участка и дома;
- расчётная площадь;
- раздел материалов и ориентировочной стоимости;
- поставщики;
- дата формирования;
- юридические и технические ограничения;
- кнопка «PDF-компредложение» в интерфейсе;
- API `/api/pdf-offer`.

PDF предназначен для коммерческой презентации концепции и не является рабочей проектной документацией или строительной сметой.
