# DomAI v49 — 3D GIZMO / SNAP

Добавлено интерактивное перемещение выбранного 3D-объекта:
- перетаскивание по плоскости участка;
- X/Z позиционирование;
- привязка к сетке 0.5 м;
- привязка к сетке 1 м;
- свободное перемещение без привязки;
- сохранение последней позиции;
- работает совместно с выбором объекта v47 и трансформацией v48.

Важно: это инструмент визуального концептуального редактирования, а не геодезическая или строительная система.
