# DomAI v36 — 3D SITE

## Добавлено
- интерактивный 3D-генплан участка;
- дом с простым объёмом, крышей, окнами и входом;
- гараж;
- баня;
- парковка;
- сад с концептуальными деревьями;
- терраса;
- мангальная зона;
- дорожки;
- ограждение участка;
- OrbitControls: вращение, масштабирование, панорамирование;
- вид сверху;
- перспективный вид;
- выбор объекта на сцене;
- использование данных генплана v35.

## Важно
Это визуальная концептуальная 3D-модель. Она не является BIM-моделью и не заменяет рабочую архитектурную, конструктивную или инженерную документацию.
