# DomAI v77 — LOAD TRANSFER

Объединены структурная сетка v73 и нагрузочная модель v72.

## Что добавлено
- вертикальная передача реакций между этажами;
- нагрузка плит по фактической площади;
- распределение реакции на несущие линии;
- расчёт реакции на колонну при наличии колонн;
- суммарная реакция на фундамент;
- среднее давление на грунт;
- единый Load Path;
- табличный отчёт по этажам;
- TXT-отчёт и JSON-экспорт.

## Ограничение
Это предварительная инженерная модель. Распределение между стенами, балками и колоннами носит концептуальный характер и не заменяет расчёт пространственной конструкции. Рабочее применение требует реальных опор, жёсткостей, сечений, материалов, сочетаний нагрузок, геологии и проверки квалифицированным проектировщиком.

## Следующий этап
v75 — расчёт отдельных конструктивных элементов по полученным реакциям: балки, плиты, колонны, стены и фундаментные участки, с передачей усилий из Load Path в проверки прочности/жёсткости.
