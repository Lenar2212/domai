# DomAI v101 — Layered Soil + Gap/Contact + Energy Control

v101 развивается поверх v100 и добавляет более строгую концептуальную модель вертикального контакта фундамента с многослойным грунтом.

## Что добавлено

- три слоя грунта с независимыми коэффициентами постели `k1`, `k2`, `k3`;
- выбор `k` в каждой Gauss-точке по координате слоя;
- начальный зазор `g0`;
- проникновение/сжатие `delta = max(0, g0 - u_n)`;
- давление `p = k_layer * delta`;
- состояния `CONTACT`, `OPEN`, `UPLIFT`;
- контактный residual `R_c = integral(N^T p dA)`;
- контактная касательная матрица `K_c = integral(N^T k_t N dA)`;
- Newton/active-set итерации;
- контроль `max |Delta U|` и `max |R|`;
- внешняя работа `W_ext = F^T U`;
- структурная энергия `0.5 U^T K_struct U`;
- контактная энергия `0.5 sum(k delta^2 dA)`;
- относительный энергетический остаток;
- patch tests для равномерного давления, нулевой нагрузки, проникновения и многослойного грунта;
- mesh/contact convergence;
- TXT/JSON отчеты.

## Интерпретация

`OPEN` означает отсутствие сжатия грунта. `CONTACT` означает положительное сжатие в Gauss-точке. `UPLIFT` используется как диагностическое состояние для точки, в которой основание находится выше заданного gap.

## Ограничения

Это **предварительная/концептуальная инженерная модель**, а не сертифицированный расчёт и не рабочая документация. В ней отсутствуют полноценный 3D-континуум грунта, трение, пластичность, консолидация, фильтрация/дренирование, грунтовые воды, сложная контактная механика, сейсмическое взаимодействие и полный нормативный комплекс по железобетону, устойчивости, трещиностойкости и продавливанию.

Перед применением результатов в проекте необходимы проверка исходных данных, независимая верификация методики и расчётов и оформление/подписание квалифицированным специалистом в соответствии с применимыми нормами и требованиями объекта.

## Patch tests v101

Patch-тесты проверяют именно контактный оператор независимо от конкретной жёсткости полной строительной модели:

1. равномерное заданное давление → интегральная реакция `p·A`;
2. нулевая нагрузка → все точки `OPEN`, давление 0;
3. заданное проникновение → положительное давление и `CONTACT`;
4. выбор разных `k` по слоям;
5. энергетическая формула линейного контактного пружинного закона.

Это не заменяет независимую верификацию полного FEM-модуля.

## Важный контроль полного расчёта

Для связанного расчёта v101 статус `Convergence=YES` допускается только при одновременном выполнении контроля приращения перемещений, reduced residual и глобального баланса внешней нагрузки/контактной реакции. Если баланс не выполнен, интерфейс показывает `CHECK`, даже если линейная система на текущем active-set решена.
