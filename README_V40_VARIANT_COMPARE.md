# DomAI v40 — VARIANT COMPARE

Добавлен визуальный режим сравнения вариантов.

Возможности:
- загрузка нескольких вариантов v39;
- карточки вариантов;
- миниатюрная 2D-схема участка;
- показатели: технический балл, число объектов, занятая площадь, число простых конфликтов;
- выбор варианта;
- применение выбранного варианта в 3D-редактор;
- v39 теперь сохраняет весь набор созданных вариантов в localStorage.

Ограничения:
миниатюры и показатели являются инструментом предварительного сравнения. Они не подтверждают соответствие ПЗЗ, ГПЗУ, пожарным требованиям, охранным зонам, инженерным ограничениям, инсоляции, рельефу, геологии или иной обязательной документации.
