# DomAI v61 — TRUE 3D

Added a real Three.js WebGL scene connected to the v60 conceptual room data:
- extruded floors;
- four walls per room;
- room labels;
- lighting;
- orbit/pan/zoom controls;
- top and isometric camera presets;
- 3D object selection;
- automatic rebuild from the 2D editor state.

This is a conceptual visualization, not structural/BIM documentation. Three.js is loaded from jsDelivr at runtime.
