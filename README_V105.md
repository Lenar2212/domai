# DomAI v105 — ENGINEERING NETWORK COORDINATION

Добавлен концептуальный координатор инженерных сетей.

## Возможности
- поиск пересечений трасс;
- контроль близости к стенам/препятствиям;
- попытка автоматического обхода по дискретной сетке A*;
- контроль разноса разных инженерных систем;
- анализ по этажам;
- визуальное выделение конфликтных участков;
- отчёт TXT и JSON;
- сохранение результата в `localStorage` как `domai105_coord`.

Системы: электрика, газ, вода, канализация, отопление.

## Ограничения
Модель является предварительной/концептуальной. Автоматический обход не доказывает допустимость прокладки через стены, перекрытия, противопожарные преграды или газовые зоны. Для рабочего проекта требуется проверка фактической геометрии, проёмов, узлов, уклонов, диаметров, сечений, электрических защит, газоснабжения, вентиляции, пожарных требований и нормативных расстояний квалифицированным проектировщиком.
