# DomAI v19 Estimate

DomAI теперь может после создания планировки показать предварительную разбивку материалов и стоимости.

Это информационный расчёт, не строительная смета и не предложение подрядчика.
Для реального продукта цены нужно получать из обновляемого каталога поставщиков/региональных коэффициентов.
