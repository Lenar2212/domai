# DomAI v47 — 3D OBJECT PICKER

Добавлен режим выбора конкретного объекта непосредственно в 3D-сцене:
1. нажмите «Включить выбор»;
2. кликните по объекту;
3. объект подсветится;
4. используйте плавающую панель материала;
5. выбранная фактура применяется только к выбранному 3D-мешу.

Поддерживаются семантические категории фасада/стены, крыши, окон, дверей, ворот и забора.

Важно: результат остаётся визуальной концепцией. Это не рабочий строительный проект и не точная спецификация материалов.
