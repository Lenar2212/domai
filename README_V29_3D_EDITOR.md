# DomAI v29 — 3D EDITOR

Версия v29 добавляет поверх v28 интерактивное редактирование концептуальной 3D-модели.

## Возможности
- выбор комнаты/стены/двери/окна прямо в 3D;
- изменение размеров выбранной комнаты;
- изменение этажности выбранной комнаты;
- добавление комнат;
- добавление дверей и окон;
- удаление пользовательских комнат и проёмов;
- сохранение концептуальной структуры проекта через `/api/projects/save`;
- локальный JSON fallback, если сервер недоступен;
- OrbitControls: вращение, масштабирование, панорамирование;
- сохранение предыдущего 3D-функционала v28.

## Важно
v29 — визуальный концептуальный редактор. Он НЕ является BIM-системой и НЕ создаёт рабочую архитектурную, конструктивную, инженерную или исполнительную документацию.

Перед строительством параметры должны быть проверены квалифицированными проектировщиками, инженерными организациями и с учётом применимых норм, геологии, участка, нагрузок и местных требований.

## Запуск
Сохраните структуру проекта и запустите существующий `backend/server.py`.
Откройте адрес сервера в браузере.

## Ограничения текущего MVP
Редактирование стен в этой версии визуальное; полноценная параметрическая BIM-топология, автоматическое перераспределение всех помещений и профессиональные CAD/BIM-экспорты ещё не реализованы.
