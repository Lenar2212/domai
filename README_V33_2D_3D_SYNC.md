# DomAI v33 — 2D / 3D SYNC

## Добавлено
- полноценная 2D-панель на Canvas;
- отображение границ дома;
- комнаты с подписями, размерами и площадями;
- выбор помещения мышью;
- перетаскивание помещений в 2D;
- привязка к сетке;
- изменение ширины/глубины/X/Z;
- пересчёт общей площади;
- события двусторонней синхронизации 2D ↔ 3D;
- сохранение проекта через API или JSON fallback.
