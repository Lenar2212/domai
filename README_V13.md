# DomAI v13

Коммерческий прототип конструктора участка.

Запуск:
`cd backend && python server.py`
затем открыть `frontend/index.html`.

Перед публичным запуском нужны HTTPS, защищённая аутентификация, production DB, резервное копирование, rate limiting, безопасная CORS-политика, юридическая проверка документов и актуальная нормативная база.
