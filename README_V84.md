# DomAI v84 — 3D FRAME SOLVER

Добавлен 3D стержневой решатель:
- 6 DOF на узел: UX/UY/UZ/RX/RY/RZ;
- локальная 12×12 жёсткость пространственного frame-элемента;
- EA, EIy, EIz, GJ;
- автоматическая локальная система координат;
- глобальная сборка K;
- закрепление узлов основания;
- решение перемещений;
- реакции;
- восстановление N, Vy, Vz, Mx, My, Mz;
- расчёт по нескольким сочетаниям G/Q/S/W;
- выбор неблагоприятного сочетания для элемента;
- предварительный U;
- критические элементы;
- TXT/JSON экспорт.

Важно:
это инженерный прототип. Он не является автоматически сертифицированным расчётом,
экспертизой или рабочей документацией. Для нормативного выпуска нужны верификация
алгоритмов, реальные сечения/материалы/узлы, устойчивость, 2-й порядок, оболочки/контакт
основания, фактические нормативные сочетания и профессиональная проверка.

Следующий этап v85:
shell-FEM для плит/стен + распределение поверхностных нагрузок в узлы + контактная
модель основания + баланс сил и независимые контрольные тесты.
