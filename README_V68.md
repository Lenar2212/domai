# DomAI v68 — STRUCTURAL MODULE

Added a preliminary constructive scheme:
- foundation type;
- load-bearing wall thickness;
- conceptual columns;
- beams;
- floor slabs;
- rafters and rafter spacing;
- material selection;
- element-by-element preliminary checks;
- conceptual specification quantities.

The module does NOT certify structural safety and does NOT by itself create legally valid working construction documentation. Final design requires project-specific calculations, source data, applicable standards, geotechnical survey, detailed drawings, connections/reinforcement and professional review/sign-off as required.
