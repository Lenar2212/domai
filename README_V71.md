# DomAI v77 — STRUCTURAL LOAD PATH

## Что добавлено
- единая предварительная модель передачи вертикальных нагрузок;
- путь: кровля → перекрытия → несущие стены/балки/колонны → фундамент → грунт;
- накопление реакций по этажам;
- распределение реакции на несущие линии;
- ориентировочная реакция на колонну;
- расчёт среднего давления под фундаментом;
- коэффициенты использования и статусы OK / ТРЕБУЕТ ПРОВЕРКИ / НЕ ПРОХОДИТ;
- автоматические предупреждения о неполной или потенциально проблемной схеме;
- текстовый инженерный отчёт;
- JSON-экспорт расчётной модели.

## Важно
Модель является предварительной инженерной оценкой и не является:
- сертификатом;
- заключением государственной/негосударственной экспертизы;
- автоматически согласованной документацией;
- рабочей конструктивной документацией;
- заменой расчёта квалифицированным проектировщиком.

Для рабочего применения нужны реальные геометрические модели, пролёты и опоры,
характеристики материалов, сочетания нагрузок, снеговые и ветровые районы,
геотехнические данные, расчёт основания и конструкций, а также проверка и
подпись ответственного специалиста.

## Следующий логический этап
v72: привязка load-path к фактической 2D/3D геометрии DomAI:
- автоматическое определение несущих стен и опор;
- tributary areas для плит и кровли;
- реальные пролёты и реакции;
- связка с балками, колоннами, фундаментами;
- структурная модель здания в JSON.
