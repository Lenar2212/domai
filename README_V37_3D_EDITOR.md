# DomAI v37 — 3D SITE EDITOR

Добавлено:
- редактирование объектов генплана прямо в 3D;
- перетаскивание мышью по плоскости участка;
- числовые X/Z;
- ширина и глубина;
- выбор объекта из списка;
- центрирование выбранного объекта;
- проверка выхода за границы;
- простая проверка пересечений;
- сохранение состояния в localStorage и попытка отправки в /api/projects/save;
- сохранение функций v36.

Ограничения:
3D-модель и проверки являются концептуальными. Это не BIM/рабочая документация и не заменяет проверку градостроительных регламентов, пожарных расстояний, охранных зон, инженерных сетей, геологии, инсоляции и других обязательных требований специалистом.
