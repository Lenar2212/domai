# DomAI v77 — STRUCTURAL CALCULATOR

Added separate preliminary checks for:
- foundation / soil pressure;
- beam strength and deflection indicators;
- slab span and deflection indicators;
- column stability indicator;
- load-bearing wall indicator;
- rafter system indicator;
- utilization coefficients and OK / WARNING / FAIL status.

Important:
The internal formulas are deliberately presented as preliminary engineering indicators, not as a certified structural solver or finite-element analysis package. Production structural calculations require project-specific models, materials, load combinations, geotechnical data, boundary conditions, detailed code checks and professional verification/sign-off.
