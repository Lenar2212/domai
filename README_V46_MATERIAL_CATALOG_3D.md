# DomAI v46 — MATERIAL CATALOG 3D

Визуальный каталог материалов для концептуальной 3D-сцены.

Категории:
- фасад;
- крыша;
- забор;
- окна;
- двери.

Каждая карточка имеет визуальное мини-превью. Нажатие применяет выбранную фактуру к соответствующей категории 3D-мешей, если сцена доступна, и сохраняет выбор в localStorage.

Материалы генерируются процедурно в браузере. Это демонстрационные визуальные фактуры, не точные текстуры конкретных производителей.

DomAI остаётся инструментом предварительной концепции. Результат не является рабочей строительной/инженерной документацией.
