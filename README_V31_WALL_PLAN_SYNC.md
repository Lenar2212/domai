# DomAI v31 — WALL PLAN SYNC

v31 добавляет параметрическое редактирование стен и связи между оболочкой дома, комнатами и проёмами.

## Возможности
- перемещение северной/южной/западной/восточной стены;
- изменение смещения стены;
- привязка к сетке;
- корректировка размеров комнат при перемещении границы;
- ограничение комнат внутри оболочки;
- привязка дверей и окон к выбранной стене;
- синхронизационное событие для 2D-плана;
- сохранение проекта через существующий API или JSON fallback.

## Ограничение
Модель концептуальная. Это не расчёт несущих конструкций, не BIM и не рабочая проектная документация. Геометрия не заменяет архитектурные/конструктивные расчёты и проверку специалистами.
