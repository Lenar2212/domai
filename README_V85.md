# DomAI v85 — SHELL / LOAD TRANSFER / CONTACT / BALANCE

Добавлен следующий уровень расчётного прототипа:
- автоматическая shell-сетка прямоугольной области;
- узловые степени свободы UX/UY/UZ;
- поверхностная нагрузка переводится в узловые силы;
- вертикальный контакт основания моделируется пружинами;
- вычисляются реакции;
- выполняется контроль равновесия «сумма нагрузок — сумма реакций»;
- максимальные перемещения;
- экспорт TXT/JSON.

Важно:
это численный инженерный прототип. Shell-жёсткость упрощена и не является полноценной
верифицированной Reissner-Mindlin/Kirchhoff FE-реализацией. Контакт грунта — вертикальные
пружины, без нелинейного отрыва, сдвига, пластичности и реальной геотехнической модели.
Нет нормативной проверки армирования, трещин, продавливания и устойчивости.
Результат не является автоматически сертифицированным расчётом или рабочей документацией.
