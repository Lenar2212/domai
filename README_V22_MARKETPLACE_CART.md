# DomAI v22 — MARKETPLACE + CART

## Новое
- Корзина на основе расчёта материалов v21.
- Расчёт итоговой суммы материалов + ориентировочной доставки.
- Параметры доставки: расстояние, вес заказа, грузоподъёмность автомобиля.
- Источник товара сохраняется в каждой строке корзины.
- Прозрачная формула ориентировочной доставки.
- API `/api/market/checkout`.

## Важное
DomAI v22 не оформляет и не оплачивает заказ у магазина. Стоимость доставки — модель-ориентир, а не тариф поставщика. Фактическая цена зависит от адреса, веса, объёма, габаритов, выбранного автомобиля, условий продавца и дополнительных услуг.

Публичные правила Петровича указывают, что стоимость доставки зависит от веса, объёма и габаритов, а разгрузка/подъём могут рассчитываться отдельно. Поэтому DomAI специально показывает доставку как оценку, а не как гарантированную цену.
