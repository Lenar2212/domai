# DomAI v24 — ACCOUNT + PROJECTS

Добавлено:
- сохранение проектов пользователя в SQLite;
- список сохранённых проектов;
- избранные материалы;
- история цен каталога;
- автоматическое начальное заполнение истории из каталога v23;
- API `/api/projects`, `/api/projects/save`, `/api/favorites`, `/api/favorites/toggle`, `/api/price-history`.

## Ограничение
Версия не является полноценной CRM/production-безопасным личным кабинетом: перед публичным запуском нужны нормальная авторизация, CSRF-защита, ограничение запросов, HTTPS, резервное копирование БД, разграничение прав и политика хранения персональных данных.

История цен отражает только записи, которыми располагает каталог DomAI; она не означает непрерывное автоматическое отслеживание сайтов поставщиков.
