# DomAI v81 — BIM / ENGINEERING LINK

Добавлена интеграция:
- чтение помещений из 2D-модели DomAI;
- группировка помещений по этажам;
- реальные площади помещений;
- G/Q/S по площади;
- расчётные нагрузки этажей;
- автоматическая предварительная схема несущих стен;
- предварительная сетка колонн;
- плиты этажей;
- фундамент и среднее давление на грунт;
- коэффициент U грунта;
- инженерный TXT/JSON отчёт.

Это связующий BIM/engineering слой. Автоматически определённые стены и колонны являются эвристической концептуальной схемой. Для рабочего расчёта необходимы реальные конструктивные решения, узлы, материалы, пролёты, геология, снег/ветер по региону и нормативные сочетания.

Следующий этап v82:
связать v81 напрямую с v79/v80: генерировать 3D FEM-узлы и элементы из реальной геометрии помещений, назначать каждому элементу материал/сечение, прикладывать G/Q/S/W к соответствующим площадям и запускать единый FEM + инженерные проверки.
