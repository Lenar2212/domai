# DomAI v102 — Инженерные коммуникации

Добавлен концептуальный редактор инженерных сетей дома и участка:

- электрика: ввод, щит, выключатели, розетки, силовые розетки, светильники, заземление;
- газ: ввод, кран, газовая колонка, газовый котёл, плита, дымоход/вентиляция;
- вода: колодец/скважина, ввод, водомерный узел, фильтр, коллектор, краны, бойлер;
- канализация: выпуск, выгребная яма/септик, ревизия, трапы, сантехнические приборы;
- отопление: котёл, коллектор, радиаторы, тёплый пол, подача, обратка, расширительный бак, насос.

## Редактор

Можно выбирать систему, тип точки, этаж, нагрузку, диаметр трубы, высоту установки и примечание. Точки размещаются кликом по плану. Трассы строятся последовательными кликами и могут иметь ветвления; кнопка «Завершить трассу» завершает текущую ветку.

Данные сохраняются локально в браузере и выгружаются в JSON/TXT.

## Ограничения

Это предварительная концептуальная схема, а не рабочая документация. Для газа, электрики, водоснабжения, канализации и отопления необходима проверка квалифицированным проектировщиком: сечения и защиты, диаметры и гидравлика, уклоны, вентиляция/дымоудаление, пожарные расстояния, запорная арматура, узлы подключения, теплотехнические и санитарные требования.
