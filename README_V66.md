# DomAI v66 — STAIRS + BALCONIES + TERRACES

Added to v65:
- conceptual stair flights between floors;
- configurable stair width and length;
- balconies on upper floors;
- configurable balcony width and projection;
- ground-floor terrace;
- configurable terrace width/depth;
- conceptual railings: glass, metal, or none;
- automatic 3D rebuild.

Important: all geometry is preliminary/conceptual. Stair structural calculations, loads, foundations, guardrail compliance and working architectural/structural documentation are not included.
