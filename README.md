# DomAI v10 SAFE

Версия с архитектурой, ориентированной на снижение юридических рисков российского сервиса.

Главные изменения:
- обязательное уведомление о статусе результата;
- два подтверждения пользователя перед генерацией/сохранением;
- предупреждение добавляется в объект проекта и ответ AI;
- отдельный legal/чек-лист;
- шаблон пользовательского соглашения;
- шаблон политики ПД;
- запрет позиционировать MVP как готовый строительный проект;
- логическая подготовка к аудиту AI-операций.

Это не делает сервис «неуязвимым» для исков. Никакой интерфейс и договор не могут гарантировать отсутствие ответственности. Они должны дополнять корректную бизнес-модель, качество продукта и соблюдение законодательства.

Для production обязательно получить юридическое заключение по конкретной модели продаж и проверить действующие требования перед запуском.


## DomAI v11 Compliance
Добавлен автоматический предохранитель:
- GREEN / YELLOW / RED;
- блокирующие риски;
- проверка исходных данных участка;
- проверка наличия инженерных изысканий и профессиональной проверки;
- версия движка и нормативной базы;
- аудит проверок;
- отдельная политика безопасного использования и launch-gates.

Это технический механизм снижения риска, а не юридическая гарантия.
