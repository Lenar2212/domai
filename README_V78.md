# DomAI v78 — FEM CORE

Добавлен первый вычислительный FEM-каркас:
- узловые степени свободы Ux/Uy;
- сборка глобальной матрицы жёсткости;
- локальная матрица 2D стержня и преобразование по направлению;
- эквивалентные узловые нагрузки;
- закрепление нижнего уровня;
- решение линейной системы методом Гаусса с выбором ведущего элемента;
- узловые перемещения;
- продольные усилия N;
- напряжения по заданной площади;
- опорные реакции;
- TXT-отчёт и JSON.

Ограничения:
- это не полноценный пространственный 3D FEM;
- нет поворотных степеней свободы и изгибной жёсткости балки;
- нет пластин/оболочек;
- нет контакта грунта;
- нет нелинейности;
- нет нормативного автоматического подбора сечений/арматуры;
- нет полного набора сочетаний нагрузок;
- не является сертифицированным расчётом или рабочей документацией.

Следующий логичный этап v79:
пространственный 3D каркас с 6 DOF на узел, 3D frame elements, EA/EIy/EIz/GJ, локальные системы координат, моменты Mx/My/Mz, поперечные силы Qy/Qz и автоматическая проверка устойчивости/перемещений.
