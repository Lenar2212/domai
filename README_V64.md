# DomAI v64 — WALL OPENINGS

Walls are now generated as conceptual segments around door/window openings:
- front/back/left/right wall segmentation;
- opening width taken from the selected door/window;
- no solid wall is drawn through the opening;
- moving/resizing an opening rebuilds the wall segments.

This remains conceptual geometry and is not a structural/BIM model or construction documentation.
