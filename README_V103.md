# DomAI v103 — Automatic Engineering Networks

Добавлен предварительный автоматический роутинг инженерных коммуникаций по координатной схеме v102.

## Возможности
- автоматическая разводка электрики, газа, воды, канализации и отопления;
- поиск источника системы (щит, ввод газа, колодец/скважина, септик/выгребная яма, котёл/коллектор);
- подключение конечных точек;
- ветвление;
- прямоугольная трассировка по плану;
- эвристика минимального присоединения ближайшей точки;
- расчёт длины трасс по заданному масштабу;
- запас трассы;
- автоматическая спецификация;
- JSON экспорт.

## Ограничения
Алгоритм является концептуальным. Он не выполняет полноценную проверку электрических нагрузок и защит, гидравлический расчёт, расчёт газоснабжения, уклонов канализации, вентиляции, пожарных требований, трассировочных расстояний и нормативных ограничений. Результат не является рабочей или сертифицированной проектной документацией.
