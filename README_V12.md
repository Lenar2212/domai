# DomAI v12 Commercial

Это расширенный прототип коммерческого сервиса.

Есть:
- регистрация/вход;
- SQLite;
- проекты пользователя;
- автоматический план помещений;
- предварительная оценка стоимости;
- автоматическая compliance-проверка;
- журналирование действий;
- юридические ограничения из v11.

Важно: это не готовая строительная САПР/BIM и не юридически проверенная коммерческая система. Перед продажей необходимы безопасность, юридические документы, актуализация нормативной базы и профессиональная проверка проектной части.
