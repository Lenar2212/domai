# DomAI v39 — LAYOUT VARIANTS

Добавлен генератор нескольких концептуальных вариантов участка.

Возможности:
- 2–12 вариантов за один запуск;
- разные схемы положения дома;
- альтернативные зоны гаража и бани;
- сад и парковка;
- терраса и мангальная зона;
- проверка границ и простых пересечений;
- технический показатель 0–100;
- выбор одного варианта;
- применение выбранной схемы к 3D-редактору через localStorage.

Показатель 0–100 является только внутренним техническим показателем алгоритма и не означает соответствие строительным или градостроительным нормам.

Ограничения:
алгоритм не проверяет ПЗЗ, ГПЗУ, красные линии, пожарные расстояния, охранные зоны, инженерные сети, инсоляцию, рельеф, геологию и иные обязательные требования. Результат предназначен только для предварительной концепции.
