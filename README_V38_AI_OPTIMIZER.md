# DomAI v38 — AI OPTIMIZER

Добавлен концептуальный автоматический оптимизатор генплана.

Он подбирает размещение:
- дома;
- гаража;
- бани;
- парковки;
- сада;
- террасы;
- мангальной зоны.

Есть:
- перебор допустимых координат по сетке;
- проверка попадания в границы;
- простая проверка пересечений;
- оценка результата 0–100 как технический показатель алгоритма, а не качество строительного проекта;
- применение результата к 3D-редактору;
- сохранение плана в localStorage.

Важно: алгоритм не проверяет ПЗЗ, ГПЗУ, красные линии, пожарные нормативные расстояния, охранные зоны, инженерные сети, инсоляцию, рельеф, геологию, санитарные ограничения и иные обязательные требования. Результат — только предварительная концепция.
